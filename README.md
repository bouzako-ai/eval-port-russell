# Port de plaisance Russell

Application de gestion des catways, des réservations et des utilisateurs de la capitainerie.
Réalisée avec Express, MongoDB, EJS et mise en ligne avec Render.

# Liens

- Application en ligne : https://eval-port-russell.onrender.com
- Documentation de l'API : https://eval-port-russell.onrender.com/api-docs
- Documentation du code (JSDoc) : ouvrir `docs/index.html`

# Lancer le projet en local

1. `npm install`
2. Créer un fichier `.env` avec `URL_MONGO`, `DB_NAME` et `SECRET_KEY`
3. `npm run dev`
